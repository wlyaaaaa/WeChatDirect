# WeChatDirect

- **这是什么：** 从本机当前可见的微信数据读取聊天或朋友圈小段上下文，也能按点名对象保存阅读包或档案。
- **我怎么用：** 告诉 AI 要看哪个账号、联系人或群、时间或关键词；命令和本机配置见 [使用说明](docs/USAGE.md)。
- **怎么知道正常：** 结果会标明已读范围、消息和媒体缺口；已导出的文件可用 `verify-export` 核对。
- **坏了怎么提醒我：** 没有自动提醒，出问题直接跟 AI 说；命令会返回错误和建议的下一步。
- **让 AI 做什么：** 让 AI 找指定聊天的相关上下文、解释引用与媒体，必要时按你点名的范围导出或保全。
- 本机缓存不等于微信全部历史；部分媒体读不到时如实保留缺口，账号不会靠昵称猜测。恢复细节见 [恢复与结果边界](docs/RECOVERY.md)。
- 可选原生 `helper` 入口支持明确账号和目标的文字、图片、文件、动态表情、语音发送，以及单次任务内的限定事件接收和实时好友申请处理；只在调用期间运行，不加载机器人插件或后台管理台。能力、配置、回执与当前版本缺口见 [原生 helper 用法](docs/USAGE.md#helper原生按次动作与任务内会话)。
